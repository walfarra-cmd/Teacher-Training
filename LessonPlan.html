ويلائم المرحلة، بثلاثة مسارات صريحة: الدعم (سقالات: قرائن بصرية، دعم صوتي، نص مظلَّل، بدايات جمل، بطاقات مفردات، بنوك شواهد)، والأساسي (مهمة مستوى الصف)، والإثراء (استنتاج أعمق، تقويم، مقارنة، كتابة ## R — ROLE Act as a certified Physics teacher working under The Saudi National Curriculum, and an expert in Bloom's Revised Taxonomy, Depth of Knowledge (DOK), mixed-ability differentiation, cooperative learning, assessment, instructional design and professional Microsoft Word design. Produce a practical, academically rigorous lesson plan ready for classroom use. Read every attachment completely before writing. ## C — CONTEXT The teacher will attach the school-approved lesson template and the relevant student-book pages, and supply: * Grade/Stage: Grade 12 · Subject: Physics * Lesson title: Light refraction · Topic: Snell's Law * Duration: 45 minutes · Class profile: mixed ability * Curriculum codes: 6Rs.01 · 6Rs.02 * Previous learning: The nature of light * Required language: English · Delivery mode: face-to-face (alternatives: online · blended) Source-control rules: * Reproduce the school template's headings, labels and administrative fields. If it conflicts with this brief, keep its administrative fields and follow the structure below. * Use only the supplied book text, vocabulary, examples and questions. Copy textbook questions exactly, with their numbering. Never invent, rewrite, simplify, paraphrase, split or renumber them, add questions that are not in the book, or invent evidence, quotations or answers. * If an essential attachment is missing or unreadable, stop and request it. * Do not pre-complete the post-lesson reflection. * Adapt every cooperative structure to the delivery mode (breakout rooms and a shared board online; seating and grouping face-to-face). ## T — TASK Create one complete, student-centred lesson plan in exactly this order: 1. **Opening:** school template title, lesson title, centred subtitle (grade, subject/topic, duration), and an introductory table containing only Class | Date | Lesson | Previous learning. 2. **Learning objectives (once only, immediately before the Plan):** table `Bloom level | Learning objective | Code` with six SMART objectives (Remember, Understand, Apply, Analyse, Evaluate, Create), progressing from lower- to higher-order thinking. Each begins with a measurable outcome, is achievable within the lesson, is linked to a supplied curriculum code, and includes measurable evidence (accuracy, number of responses, textual evidence, word count or rubric score). 3. **Integrated Plan (the instructional core):** five columns: `Stage | Student actions / Planned activities | Cooperative learning | Differentiated activity | Time in minutes`. Eight stages whose times total the lesson duration exactly. Write from the students' perspective (what they do, say, read, discuss, analyse, write), not teacher actions. Each stage uses a different cooperative structure: * 1 Warm-up: activate prior knowledge, short hook or instant poll, link the title to previous learning (Think–Pair–Share). * 2 Vocabulary teaching: supplied-page vocabulary only; infer from context, then check; match; use orally or in short sentences (mixed-attainment triads). * 3 Prediction: examine the title, illustrations and visible clues; evidence-based predictions explained by a clue (Gallery Walk or Prediction–Evidence Pairs). * 4 Gist reading: read the extract, identify the main idea or viewpoint, answer the book's gist question (paired or echo reading). * 5 Specific information: scan and reread, answer the book's specific-information questions, highlight the exact evidence (Numbered Heads Together). * 6 Detailed reading analysis: answer the analysis and inference questions, analyse structural and linguistic features, find evidence, explain the writer's effect, evaluate success when asked (Jigsaw Expert Groups: experts analyse assigned questions, then teach their home groups). * 7 Application and production: answer the application questions, complete a speaking or performance task, produce the required oral or written response using lesson vocabulary and features (Hot-Seating or role-play), with "Two Stars and a Wish" peer feedback. * 8 End/Close/Reflection/Summary: all closure inside this final row, with four DOK exit-ticket prompts (DOK 1 Recall, DOK 2 Skill/Concept, DOK 3 Strategic Thinking, DOK 4 Extended Thinking), ending with one deep Socratic question linking the text's central idea, its treatment of time, structure or perspective, and the learner's real life and judgement of others. Students answer individually first, then discuss in a Socratic Pair-Share or Reflective Circle. * In stages 4–7, insert the exact wording and numbering of the relevant book questions inside that stage's "Student actions / Planned activities" cell, once only, never in a separate section. * Every row has a different differentiated activity that fits its stage, with three explicit tiers: **Support** (visual cues, audio support, highlighted text, sentence stems, vocabulary cards, evidence banks, guided charts), **Core** (the grade-level task), **Extension** (deeper inference, evaluation, comparison, alternative writing, structural analysis, independent creation). 4. **Student success criteria:** table `Success criterion | Evidence of success`, each criterion beginning "I can…", covering: main idea or viewpoint, exact textual evidence, effect of structure and language, treatment of time, participation in the cooperative task, the required written or oral response. 5. **Assessment:** * Formative: only methods that serve the Plan (Padlet posts, peer correction, instant polling, cooperative questioning, teacher observation, digital feedback), stating where each occurs and what evidence it collects. * Summative: a short written task aligned with the highest objective and the book's task, stating perspective or text type, length, required features, vocabulary or structures and organisation. Add a 16-mark analytic rubric with five columns `Criterion | 4 — Exceeding | 3 — Meeting | 2 — Developing | 1 — Needs support`, four criteria (Idea and task integration; Inference and perspective; Vocabulary and sentence structure; Organisation and flow) with specific descriptors for every level, and bands: 13–16 Exceeding/Secure, 9–12 Meeting/Developing securely, 5–8 Emerging, 0–4 Substantial support needed. 6. **AI and interactive digital tools:** table `Stage | Tool (active link) | Type of activity | Purpose`, chosen only where they improve the stage, from Mentimeter, Wordwall, Nearpod, Padlet, Quizizz, Kahoot, Canva, Google Forms. Each tool name is a real clickable hyperlink to its official website, with a specific classroom activity and purpose. Tools support, never replace, reading, discussion and textual analysis. The Stage 8 exit-ticket tool appears here only. 7. **Recommended teacher AI tools:** table `AI tool (active link) | Best use in this lesson` for MagicSchool AI, Diffit for Teachers, Google Gemini and Claude (clickable official links), explaining support for differentiation, vocabulary scaffolding, model responses, DOK prompts, rubric-based feedback and sentence building. Add beneath it: "Teacher safeguard: AI tools support preparation and differentiation only. The supplied textbook extract and questions remain authoritative and must not be rewritten or replaced." 8. **Reflection and Next steps:** keep both sections, with the school template's original headings and questions, empty for the teacher to complete after the lesson. No model answers and no claims that activities succeeded. ## F — FORMAT Deliver one editable Microsoft Word document (.docx): * A4 portrait, UTF-8, Arial, body #111111 at 14 pt (Plan-table text may be reduced slightly so book questions stay legible). * Title 22 pt bold centred, subtitle 16 pt centred, section headings 18 pt bold, subsection headings 15–16 pt bold, all in navy #0A2A66, with a navy divider under section headings. * Thin navy page frame on every page and a centred page-number footer. * Tables: named header row filled #DDDDDD with bold navy text, repeated across pages; borders navy #0A2A66 at about 1.5 pt; alternating rows #F2F2F2 and #E6E6E6 (light blue in the digital-tools table); consistent padding and vertical alignment; rows expand naturally with no clipping, overlap or truncation; each stage kept together where possible. * Prohibited: repeated objectives or objectives in the opening table, a standalone "Comprehension Questions", question-mapping, "Closure" or DOK section, reworded or invented book questions, pre-completed reflections, thick decorative borders, unlinked tool names. Before delivering, verify: objectives appear once, immediately before the Plan; stage times total the lesson duration exactly; every book question appears once in its stage; DOK and Socratic prompts appear only in Stage 8; the Plan is student-perspective with a distinct cooperative structure and Support/Core/Extension differentiation in every stage; every tool name is a working link; Reflection and Next steps follow the school template. Then render the document, inspect every page, fix any clipping, row splitting, overlap, orphaned text, inconsistent borders or blank pages, and deliver only the final verified .docx.

What makes this prompt strict. Its source-control rules make the AI copy the textbook questions exactly, never renumber or invent them, and stop to ask if an attachment is missing. It ends with a self-check the AI must run before handing you the file. Those two parts are what stop a convincing but invented lesson plan.

Build a single-file, production-ready, interactive HTML page for خطة درس مادة الفيزياء للصف الثاني ثانوي ("الطاقة الحرارية", الفصل السادس). The webpage must serve as both a live editable web document and a clean, perfectly formatted PDF document, with correct Arabic letter joining, correct bracket direction, intact English words, zero text clipping and zero page-wrapping issues. ### 1. TECHNICAL RULES - Single-file HTML (include all CSS and JS within the same file). - Use `<html lang="ar" dir="rtl">` and `<meta charset="utf-8">`. - DO NOT use html2pdf.js, html2canvas, jsPDF or ANY library that converts HTML to an image or re-draws text. They break Arabic shaping and bracket direction. PDF export MUST be done only through the browser's native print engine (`window.print()` then "Save as PDF"). - Responsive, clean, paper-document aesthetic centered on screen with a light background (`#f4f6f9`). ### 2. TOP ACTION CONTROL BAR (NON-PRINTING) - Fixed or top-aligned control bar containing: 1. Title banner:"خطة الدرس اليومية — فيزياء للصف الثاني ثانوي". 2. "Lock Editing / Enable Editing" button: Toggles `contenteditable="true/false"` across the card. 3. "Save as PDF" button: calls `printPDF()`. 4. "Print" button: calls `window.print()`. 5. Live toast notification system (`#toast-msg`). - Under the buttons show a small instruction line: "In the print window choose 'Save as PDF', untick 'Headers and footers', tick 'Background graphics'." - Must be hidden during printing using `@media print { .no-print-bar { display: none !important; } }`. ### 3. EXACT DOCUMENT SECTIONS & STRUCTURE The central document card (`#lessonPlanCard`) must contain the following sections in this exact order: 1. **Header Metadata Table:** - CLASS:"الصف الثاني ثانوي" (mixed ability) - DATE: Blank underline for teacher entry - Lesson: "الطاقة الحرارية" - Previous learning: اكتب هنا خبرة تعليمية سابقة مثلا : تعريف الطاقة وأشكالها 2. **Learning Objectives Table (Mapped to Bloom's Taxonomy & Curriculum Codes 6Rs.01 & 6Rs.02):** - 3 columns: `Bloom Level` | `Learning Objective` | `Code` - Covers all 6 levels: Remember (6Rs.01), Understand (6Rs.02), Apply (6Rs.02), Analyse (6Rs.02), Evaluate (6Rs.01), Create (6Rs.01). 3. **Plan (8 Student-Centred Stages, 45 Minutes Total):** - 5 columns: `Stage` (15%) | `Student Actions / Planned Activities` (31%) | `Cooperative Learning` (21%) | `Differentiated Activity` (24%) | `Time` (9%). - Stages (replace with your lesson's stages, timings and textbook question numbers): 1. Warm-up (4 min) — Think–Pair–Share & instant word cloud. 2. Key terms (5 min) — the lesson vocabulary; Vocabulary Triads. 3. Prediction (4 min) — Lesson subject & unit cover analysis; Gallery Walk. 4. Gist reading (5 min) — Exact Question 1; Paired Aloud Reading. 5. Specific information (7 min) — Exact Questions 2a–2c; Numbered Heads Together. 6. Detailed reading analysis (10 min) — Exact Questions 3a–3b & 4a–4c; Jigsaw Expert Groups. 7. Application and production (6 min) — Exact Questions 5a–5c (Hot-seating & viewpoint writing). 8. End/Close/Reflection/Summary (4 min) — Socratic exit ticket across DOK 1–4 and deep life reflection. - Differentiation column must explicitly state `Support`, `Core`, and `Extension` paths for every single row. 4. **Student Success Criteria Table:** - 2 columns: `Success Criterion` ("I can...") | `Evidence of Success`. 5. **Assessment Section:** - **Formative Assessment:** Paragraphs on Padlet, Peer Correction, and Instant Polling (Mentimeter/Quizizz). - **Summative Assessment Task:** 80–100 word paragraph on the lesson topic (16 Marks total). - **Summative Marking Rubric Table:** 5 columns (`Criterion`, `4 — Exceeding`, `3 — Meeting`, `2 — Developing`, `1 — Needs Support`). Criteria: Idea & task integration, Inference & perspective, Vocabulary & sentence structure, Organisation & flow. Includes performance bands breakdown. 6. **AI and Interactive Digital Tools Table:** - 4 columns: `Stage` | `Tool (Active Link)` | `Type of Activity` | `Purpose`. - Tools with target="_blank" links: Mentimeter, Wordwall, Nearpod, Padlet, Quizizz, Canva, Google Forms. 7. **Recommended Teacher AI Tools for Differentiation Table:** - 2 columns: `AI Tool (Active Link)` | `Best Use in This Lesson`. - Tools: MagicSchool AI, Diffit for Teachers, Google Gemini, Claude. Includes a bold Teacher Safeguard note. 8. **Reflection & Next Steps Sections:** - Formatted box notes with official reflection prompts and future lesson planning space. ### 4. STYLING & DESIGN SYSTEM - **Palette:** Navy `#0A2A66` (headings & borders), Charcoal `#111111` (body text), Gray `#DDDDDD` (table headers), `#F2F2F2` / `#E6E6E6` (alternating row fills), `#EBF3FA` / `#D6E4F0` (blue tool highlights). - **Typography:** `font-family: Tahoma, Arial, "Segoe UI", sans-serif` (system fonts only, no web fonts). Body font size `10pt`, line-height `1.6`. Table headers `9pt` bold dark navy. - **Layout:** - Card max-width: `800px`, `border: none`. - All tables: `width: 100%`, `table-layout: fixed`, `border-collapse: collapse`. - All `td` and `th`: `padding: 5px 6px`, `border: 1pt solid #0A2A66`, `vertical-align: top`, `text-align: start`, `overflow-wrap: break-word`, `word-break: normal`. - `tr { page-break-inside: avoid !important; break-inside: avoid !important; }`, `h2, h3 { page-break-after: avoid !important; break-after: avoid !important; }`, `thead { display: table-header-group; }`. - **Print CSS (required):** `@page { size: A4; margin: 10mm; }` `@media print { body { background: #fff; } #lessonPlanCard { max-width: none; width: 100%; box-shadow: none; margin: 0; } * { -webkit-print-color-adjust: exact; print-color-adjust: exact; } .no-print-bar { display: none !important; } }` ### 5. ARABIC / ENGLISH MIXED-TEXT RULES - Set `dir="rtl"` on `<html>` and on `#lessonPlanCard`. Do NOT use `dir="auto"` and do NOT use `unicode-bidi: plaintext`. - Wrap each English term, abbreviation or number-with-Latin-text (e.g. Think–Pair–Share, Jigsaw, IGCSE, 6Rs.01, Padlet, DOK 1–4, min) in `<bdi dir="ltr">...</bdi>`. - Put any text that contains brackets in Arabic context inside the RTL cell as plain text (e.g. `(مختلط القدرات)`), and write English-only bracketed text as `<bdi dir="ltr">(Bloom's Taxonomy)</bdi>` so the brackets keep the correct direction. - FORBIDDEN CSS (they break Arabic joining): `letter-spacing` other than normal, `font-kerning: none`, `font-variant-ligatures: none`, `text-rendering: geometricPrecision`, `text-transform`, `text-align: justify`. - Narrow columns (Stage, Time, Code) must fit the longest English word at 9pt; if not, reduce that cell to `8.5pt` instead of letting it break mid-word. ### 6. JAVASCRIPT - `toggleEditMode()`: switches `contenteditable` on `#lessonPlanCard` and updates the button label. - `showToast(msg)`: shows `#toast-msg` for 4 seconds. - `printPDF()`: function printPDF() { const oldTitle = document.title; document.title = 'Lesson_Plan_Physics_Thermal_Energy'; setTimeout(() => { window.print(); document.title = oldTitle; }, 400); } - No external scripts are needed in this page.
